# 学校展示说明 / 学内向けデモ説明

更新：2026-11-10。本文件是可复用材料，没有发送给任何人。这是未来达到条件后的展示准备。当前只有只读示例任务列表、内存计数练习与官网概念视觉，尚无可用 Web MVP；先由学生实现并验证功能，再使用下面脚本。Cadence 为独立项目，尚无学校背书或教务接入许可。

## 展示前条件

有可运行且已验证的手动日程/待办功能，能明确区分默认内存与选择保存；JSON 导入预览、取消、替换、导出、失败和清除已通过验证；隐私说明与实际代码一致。当前尚未达到这些条件。现在仅可展示官网概念，并明确说“计划实现”。

## 中文：未来约三分钟展示脚本

**开场**：Cadence 是主要面向学生、也适合教师等用户的时间管理软件。课程、会议和个人安排放在同一处，不需要学校账号。希望通过展示了解实际需求，不将其介绍成学校官方系统。

**演示**：用虚构数据打开今天与周计划；手动添加课程或会议，设置有结束日期的每周重复；修改或删除安排；添加并完成待办。切换日语、英语、中文。展示默认内存模式、主动选择本机保存、JSON 导出、导入预览及整份替换说明。使用干净的演示浏览器环境，不展示真实课表。

**试用范围**：手工日程、待办与本地数据操作；没有学校登录、教务同步、后台、CSV、系统通知或单次调课。桌面是长期目标，未来初期 Web 版也不代表完整桌面产品完成。

**数据处理**：默认仅在当前页面内存中。用户选择后才保存至该浏览器的 `localStorage`，不上传到 Cadence 后台；托管服务仍处理页面访问请求。浏览器存储未加密且可能被清除；共享电脑使用默认内存模式。JSON 含私人安排，最多 1 MiB、2,000 项，预览确认后整份替换。清除不能撤回已下载或已分享文件。

**希望获得的反馈或支持**：学生与教师的日程需求、语言与无障碍问题；协助招募少量自愿试用者、提供虚构/脱敏样例、介绍合适的校内联系人。若未来考虑教务导入，再单独咨询官方格式、许可范围与维护责任。

## 日本語：実装・検証後の3分程度の説明

**現状**：現在は学習用の読み取り専用タスク一覧とプロジェクトサイトの概念図のみで、利用可能な Web MVP はありません。以下は実装・検証後に使う説明案です。

**紹介**：Cadence は学生を主な対象とし、教員などにも使っていただける時間管理アプリです。授業、打合せ、私用をまとめて扱い、大学アカウントは不要です。大学の公式サービスではなく、実際の利用ニーズについてご意見を伺うための独立した開発計画です。

**操作例**：架空の予定で「今日」と「週」を表示し、授業や打合せを手入力します。終了日付きの毎週の繰り返し、予定の編集・削除、タスクの追加・完了を示します。日本語・英語・中国語の切替、メモリ内の利用、任意のブラウザ保存、JSON の書き出し・取込みプレビュー・全件置換を説明します。確認済みの機能だけを実演します。

**試用範囲**：手入力の予定とタスク、本機でのデータ操作が対象です。大学認証、教務同期、バックエンド、CSV、システム通知、繰り返し予定の一回だけの変更は含みません。初期 Web 版は、完成したデスクトップ製品を示すものではありません。

**データ**：初期状態はページのメモリ内のみです。利用者が選んだ場合だけ、そのブラウザの `localStorage` に保存します。Cadence のバックエンドへのアップロードはありませんが、配信元はページへのアクセスを処理します。保存は暗号化されず、ブラウザ操作などで失われる場合があります。共用端末ではメモリ内での利用を推奨します。JSON は私的な予定を含み、1 MiB・合計2,000件までを検証し、確認後に全件置換します。削除しても書き出したファイルや共有済みコピーは消えません。

**ご相談**：学生・教員の予定管理上の課題、言語・アクセシビリティ、少人数の任意試用、架空または適切に匿名化した例、担当窓口の紹介についてご意見を伺いたいと考えています。将来の教務連携は、公式形式、利用許可、運用責任を別途確認してから検討します。

## 独立使用与正式集成 / 単独利用と正式連携

手动使用不以学校审批或身份为门槛。学校愿意看演示、老师提供建议或学生同意试用，都不表示获得认证/API 权限。正式连接仍按 [UNIVERSITY_INTEGRATION.md](UNIVERSITY_INTEGRATION.md) 单独确认。

手入力での単独利用に大学の所属確認は求めません。デモへの参加、教員の助言、学生の試用同意は認証や API 接続の許可を意味しません。正式連携は別の手続きとして確認します。
