# Editorial image provenance

Created for Cadence on 2026-11-11 with the built-in `image_gen` tool. The original output is kept in `illustrations/journal-editorial.png` (1536 × 1024). The website uses smaller WebP exports made by `tools/export_artwork.cjs`; these change file size and resolution, not the composition. The original PNG remains unchanged.

Brand assets, interface icons, state illustrations, patterns and the sharing card come from the project's SVG source in `tools/build_artwork.py`. They are separate from this generated image. The prompt below records how the original was made; it is not a claim that the pictured planner exists.

The current product is a general-purpose local planner for work, personal life and study. Its quiet-journal style keeps this image and the independent palette. The word "academic" in the archived prompt describes the original art direction, not a school-only audience or a dependency on school access. The prompt is preserved as provenance rather than rewritten after generation.
