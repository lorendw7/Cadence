データとプライバシー

最終更新日：2026-11-10

現在のアプリ

現在は「今日」の仮画面と独立したタスクモデルの学習用コードがあり、授業や個人の予定を入力・保存する機能はありません。アカウント、学校との接続、広告・解析 SDK は実装していません。学校の認証情報や学生の時間割を受け取る機能もありません。

予定している端末内保存

デスクトップ版は、授業、個人の予定、課題と設定を端末内に保存し、手入力・ファイル取込は登録なしで利用できる設計です。個人の予定をサーバーへ送信せず、端末間のクラウド同期は現在の対象外です。

検討中の学校連携

Cadence は九大生のための独立プロジェクトで、大学の公式サービスではありません。任意の学校ログインと本人の時間割の読取専用取込は、大学の承認と提供方法の確認を前提に検討します。現在は承認も接続機能もありません。学校のパスワードを収集・保存せず、認証情報を共有ファイル、バックアップ、問題報告に含めない設計とします。実装前に、取得する情報、保存先、接続解除と削除の方法を案内します。

候補として検討する Web 版

ブラウザーで使う予定管理システムは候補段階です。この紹介サイトはそのシステムではなく、時間割の入力・アップロード機能はありません。Web 版は保存先、共有端末での利用、ブラウザーデータ削除時の復元方法などを検証してから判断します。ブラウザー内保存はバックアップを意味しません。通信やサーバー処理が必要になる場合は、扱うデータと利用者の選択肢を公開し、この説明を更新してから提供します。

共有ファイルとバックアップ

時間割の共有と完全バックアップは別機能として実装します。時間割ファイルには個人の予定、課題、私的なメモを含めません。完全バックアップには私的情報が含まれるため、他の人へ渡す前に確認してください。ファイルの保存・送信は利用者が選びます。これらはまだ未実装です。

削除と更新

データの削除・復元機能は実装予定です。デスクトップアプリをアンインストールしてもデータが残る場合があるため、アンインストールだけで削除されるとは案内しません。

今後の自動保存・集計・通知

編集途中の下書きと週の集計は端末内で扱う予定です。集計の送信や利用追跡は行いません。通知は利用者が有効にし、表示する個人情報も選べる設計です。これらは未実装です。

このウェブサイト

言語の選択はブラウザーの localStorage に保存します。このサイトに解析スクリプトはありませんが、閲覧時は GitHub Pages の配信サーバーへ通信します。リンク先にはそれぞれのサービスの取り扱いが適用されます。

お問い合わせ

GitHub のリポジトリから報告できます。公開 Issue に学校のパスワードや認証情報、個人の時間割、共有したくない予定、完全バックアップを添付しないでください。機能を実装・変更する前に、このページも更新します。

Data and privacy

Last updated: 2026-11-10

Current application

The app contains a Today placeholder and a separate task-model learning exercise, with no course or personal-plan entry or storage. It has no implemented accounts, university connection, advertising or analytics SDK. It has no feature that receives university credentials or students' timetables.

Planned local storage

The desktop app is designed to keep courses, personal plans, tasks and settings on the device, with no registration required for manual planning or file import. Personal plans will not be sent to a server. Cloud synchronization between devices is outside the current scope.

University integration under review

Cadence is an independent project for Kyushu students, not an official university service. Optional university sign-in and read-only import of your own timetable depend on university approval and an agreed access method. Neither approval nor connection functionality is in place. The design excludes collecting or storing university passwords and excludes authentication secrets from shared files, backups and issue reports. Before implementation, we will explain which data is obtained, where it is stored, and how to disconnect and delete it.

A candidate Web app

A browser-based planner is a candidate under review. This project website is not that system and has no timetable entry or upload feature. A Web app requires evaluation of storage, shared-device access and recovery after browser data is cleared. Browser storage alone is not a backup. If network or server processing is needed, we will disclose the data involved and user choices, and update this notice before offering it.

Shared files and backups

Timetable sharing and full backup will be separate features. Timetable files will exclude personal plans, coursework and private notes. A full backup will contain private information; review it before giving it to anyone. You choose where files are saved and how they are sent. These features are not implemented yet.

Deletion and updates

Explicit data deletion and restore are planned. Uninstalling a desktop application may leave its data behind, so uninstalling alone is not described as erasing it.

Planned drafts, statistics and notifications

Editing drafts and weekly summaries are designed to remain on your device, without reporting statistics or tracking usage. Local notifications will be opt-in, with control over personal details shown. These features are not implemented yet.

This website

The language choice is stored in your browser's localStorage. The site includes no analytics scripts, but visiting it sends requests to GitHub Pages hosting. Linked services have their own data handling.

Contact and changes

You can report issues through the GitHub repository. Do not attach university passwords or authentication secrets, private timetables, personal arrangements or full backups to public issues. This page will be updated before features are introduced or data handling changes.

数据与隐私

最后更新：2026-11-10

当前应用

当前为“今天”占位页与独立的任务模型学习代码，尚无课程或个人安排的录入与保存功能。未实现账号系统或学校连接，也未引入广告或统计分析 SDK。没有接收学校认证信息或学生课表的功能。

计划中的本地保存

桌面版计划将课程、个人安排、任务和设置保存在设备内，手动安排与文件导入无需注册。个人安排不发送到服务器，跨设备云同步不在当前范围内。

评估中的学校接入

Cadence 是面向九大学生的独立项目，并非学校官方服务。可选的学校登录与本人课表只读导入，以学校批准和确认数据提供方式为前提，目前尚未获批或实现。设计要求不收集或保存学校密码，认证秘密信息不得进入分享文件、备份或问题报告。实现前将说明读取哪些信息、保存在哪里，以及如何断开连接和删除数据。

作为候选的 Web 系统

浏览器中的日程系统仍是候选。当前官网并非该系统，没有课表录入或上传功能。Web 方案需要先评估数据存放位置、共用电脑上的访问保护，以及清除浏览器数据后的恢复方式。浏览器内保存本身不等于备份；如果需要联网或服务器处理，将先公开涉及的数据与用户选项，并更新本说明，再提供功能。

分享文件与完整备份

课表分享与完整备份将是两个独立功能。课表文件不包含个人安排、作业和私密备注；完整备份会含有个人信息，交给他人前请确认内容。保存位置和发送方式由用户自行选择。这些功能当前尚未实现。

删除与更新

计划提供明确的数据清除与恢复功能。桌面应用卸载后可能仍保留用户数据，因此不会将卸载描述为已彻底清除数据。

计划中的草稿、统计与通知

编辑草稿和周回顾计划只在本机处理，不上传统计数据，不追踪使用行为。本地通知由用户主动开启，并可控制是否显示私人内容。这些功能尚未实现。

这个网站

语言选择保存在浏览器的 localStorage 中。本站未加入统计脚本，但访问网站会向 GitHub Pages 托管服务发送请求，链接到的服务有各自的数据处理方式。

反馈与变更

可以通过 GitHub 仓库反馈问题。请不要在公开 Issue 中附上学校密码或认证秘密信息、私人课表、个人安排或完整备份。推出新功能或变更数据处理方式前，本页会同步更新。
