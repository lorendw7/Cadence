02 / LOCAL BY CHOICE

予定は手元に。残し方は自由に。

未実装の設計です。初回に「この端末に保存」か「一時的に使う」を選びます。基本のローカル利用に、アカウントやクラウドは必要ありません。

データの扱いを詳しく読む↗
  1. 1

    最初に、残し方を選ぶ

    端末内保存と一時利用のどちらも、アカウントなしで使える設計です。保存を選ぶ前に、個人の日程をディスクへ書き込みません。

  2. 2

    整えたら、自分で保存する

    編集画面には「保存」と「キャンセル」を設ける計画です。保存した予定はオフラインで再び開けるようにします。未保存の入力は異常終了で、一時利用の内容は終了で失われます。

  3. 3

    大切な予定は、自分で備える

    個人用のバックアップファイルと、確認してからの復元を計画しています。初版の端末内データとバックアップは暗号化しません。別の控えも自分で保管できます。

03 / A PROJECT IN PROGRESS

今あるものから、一歩ずつ。

開発計画を GitHub で読む↗

  1. 実装済み · 学習用アプリ

    タスクの基本操作

    デスクトップの学習用アプリでは、追加・完了・削除・直前の削除の取り消しが動きます。データはメモリー内だけで、終了すると失われます。

  2. 計画中 · 最初のローカル版

    毎日の予定と、端末内保存

    まず Windows で、明示的な保存、個人の予定、今日・週間表示、基本の毎週繰り返し、バックアップを実装します。macOS と Linux の公開は各環境での検証後です。

  3. その後 · 任意の補助機能

    入力の手間を、少し軽く

    スクリーンショットや表から、修正できる下書きを作る計画です。任意の AI は自分の API キーを使い、費用がかかる場合があります。学校接続は別の拡張で、Web や同期はその接続に必要な場合だけ検討します。

ここは構想を紹介するサイトで、ブラウザー版の手帳ではありません。ダウンロードできる製品版はまだなく、学習用アプリに保存機能はありません。

使い始める前に。

?
無料で使えますか？+

はい。ローカル版は無料で、アカウントや定額契約なしで使える方針です。製品版はまだ公開していません。任意のクラウド AI は自分の API キーを使い、提供元から料金が発生する場合があります。基本の利用に AI は不要です。

このプレビューに入力した内容は残りますか？+

残りません。表示切替とチェック操作は、架空のデータを使ったデザイン例です。ここでの操作を保存する機能はありません。将来の端末内保存や JSON バックアップは未実装です。

入力したデータは送信されますか？+

このサイトに個人の予定の入力・アップロード機能はありません。ページの表示には GitHub Pages への通信があります。開発中のローカル版は送信なしで使う設計です。任意の AI を使う場合だけ、内容と送信先を確認してから送る計画です。

オフラインでも使えますか？+

基本のタスク、予定、端末内保存はオフラインで使える設計です。予定表示や保存はまだ未実装です。Web や同期は学校接続に必要な場合だけ検討し、ローカル利用の条件にはしません。
