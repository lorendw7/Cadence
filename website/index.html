一週間を、自分のペースで

授業だけで、一日は終わらない。

時間割を軸にしながら、勉強も約束も自分の時間も。ひとつの週の中で、それぞれを見失わない設計です。

01

学期のリズムに合わせる

時限、奇数・偶数週、指定週の授業に対応する予定です。一回だけの休講や振替も、元の授業から整理します。

02

放課後も、同じ予定表に

自習、サークル、友だちとの約束。授業の合間や夕方の予定を並べ、重なりをわかりやすく示します。

03

締切は、予定と分けて

課題は科目に紐づけ、締切と完了を管理。試験は時間のある予定として、週の中に表示します。

時間割に、無理をさせない

毎週同じとは、限らないから。

「今週だけ教室が変わった」「次の授業は火曜に振替」。その回だけを変更して、学期全体の予定はそのままに。

  • ✓第一週と時限を、学校に合わせて設定
  • ✓奇数週・偶数週・指定週を選択
  • ✓一回だけの変更を、あとから元に戻す

クラスメートと使うために

共有するのは、時間割だけ。

時間割をプレビューしてファイルで渡す。個人の予定、課題、私的なメモは共有ファイルに含めない設計です。

気になること

今すぐダウンロードできますか？+

まだ完成版はありません。現在は Today の仮画面と開発用の土台があり、ここに載せた画面はデザインイメージです。検証した配布版ができたら、このサイトで案内します。

登録やクラウド接続は必要ですか？+

予定していません。端末内の保存と、利用者が選ぶファイル共有・バックアップを中心に開発します。外部カレンダーとの同期も対象外です。

休講や振替授業に対応しますか？+

一回だけの休講、日時・教室の変更と復元を計画しています。祝日だからといって、自動的に授業を消すことはしません。

クラスメートに自分の予定も見えますか？+

時間割の共有形式には個人の予定、課題、私的なメモを含めない設計です。すべての情報が入る完全バックアップとは、入口もファイルも分けます。

A few things you might wonder

Can I download it now?+

Not yet. The current app is a Today placeholder with the development foundation in place. The interface on this page is a design concept. We will add downloads when tested packages are ready.

Will I need an account or cloud connection?+

Neither is planned. The app will focus on local storage, user-directed file sharing and backup. External calendar synchronization is outside the scope.

What about cancelled or rescheduled classes?+

We plan to support changing or cancelling a single occurrence and restoring it later. A public holiday will never automatically remove a class.

Will classmates see my personal plans?+

The timetable format is designed to exclude personal plans, coursework and private notes. Full backups contain private data and will have a separate entry point and file format.

你可能想了解

现在可以下载使用了吗？+

还不可以。当前应用是“今天”占位页和基础工程，本页界面为设计示意。验证过的安装包准备好后，官网会提供下载入口。

需要注册账号或连接云端吗？+

不需要，这些不在规划中。我们会围绕本地保存、用户主动进行的文件分享和备份来开发，也不接入外部日历同步。

临时停课或调课怎么办？+

计划支持仅修改或取消某一次课程，之后可恢复原安排。学校校历不同于法定节假日，不会因为是假日就自动删掉课程。

分享课表会暴露个人安排吗？+

课表分享格式明确排除个人安排、作业和私密备注。包含私人数据的完整备份，会使用独立的入口和文件格式。
