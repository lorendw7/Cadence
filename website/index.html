一週間を、自分のペースで

授業だけで、一日は終わらない。

時間割を軸にしながら、勉強も約束も自分の時間も。ひとつの週の中で、それぞれを見失わない設計です。

01

学期のリズムに合わせる

時限、奇数・偶数週、指定週の授業に対応する予定です。一回だけの休講や振替も、元の授業から整理します。

02

放課後も、同じ予定表に

自習、サークル、友だちとの約束。授業の合間や夕方の予定を並べ、重なりをわかりやすく示します。

03

締切は、予定と分けて

課題は科目に紐づけ、締切と完了を管理。試験は時間のある予定として、週の中に表示します。

時間割に、無理をさせない

毎週同じとは、限らないから。

「今週だけ教室が変わった」「次の授業は火曜に振替」。その回だけを変更して、学期全体の予定はそのままに。

  • ✓第一週と時限を、学校に合わせて設定
  • ✓奇数週・偶数週・指定週を選択
  • ✓一回だけの変更を、あとから元に戻す

クラスメートと使うために

共有するのは、時間割だけ。

時間割をプレビューしてファイルで渡す。個人の予定、課題、私的なメモは共有ファイルに含めない設計です。

毎日、必要なことから

開いたら、今日やることがわかる。

計画中：今日の未完了タスクを件数とリストで表示。期限切れと日付のないタスクは分けて残し、授業と個人の予定はその下に並べます。主な入口は「今日・週間・タスク」の三つです。

01

入力を、残しておく

時間割をアプリ内で編集し、下書きを端末に自動保存する設計です。保存状況と失敗を表示し、保存済みの下書きは次回復元。確定前の内容は時間割に反映しません。

02

一週間を、静かに振り返る

授業と個人の予定の計画時間、日ごとの予定量、タスク完了を端末内で集計する予定です。計画時間と実際の学習時間は区別し、サーバーや有料 API は使いません。

03

必要な予定だけ、お知らせ

授業・予定・締切の前にローカル通知を受け取れるよう計画しています。まずはアプリ実行中を対象に、許可と通知時刻を選択。終了後の通知は OS ごとに別途検証します。

  1. 入力を残す

    下書きは端末内へ。保存できたかを表示。

  2. 確認して反映

    内容を確認してから、正式な予定に。

  3. どの画面でも同じ予定

    今日・週間・振り返りを一緒に更新。

気になること

今すぐダウンロードできますか？+

まだ完成版はありません。現在は Today の仮画面と開発用の土台があり、ここに載せた画面はデザインイメージです。検証した配布版ができたら、このサイトで案内します。

登録やクラウド接続は必要ですか？+

手入力・ファイル取込による基本機能は、登録なしでオフライン利用できる設計です。学校との連携を選ばなくても利用できるようにします。端末間のクラウド同期は現在の対象外です。

九大のアカウントや時間割と連携しますか？+

大学の承認を前提に、任意の学校ログインと本人の時間割の読取専用取込を調査します。認証と時間割データへのアクセスは別途確認が必要で、現在は未承認・未実装です。学校のパスワードを収集する機能は作りません。

休講や振替授業に対応しますか？+

一回だけの休講、日時・教室の変更と復元を計画しています。祝日だからといって、自動的に授業を消すことはしません。

クラスメートに自分の予定も見えますか？+

時間割の共有形式には個人の予定、課題、私的なメモを含めない設計です。すべての情報が入る完全バックアップとは、入口もファイルも分けます。

A few things you might wonder

Can I download it now?+

Not yet. The current app is a Today placeholder with the development foundation in place. The interface on this page is a design concept. We will add downloads when tested packages are ready.

Will I need an account or cloud connection?+

Manual planning and file import are designed to work offline without registration. You will be able to use them without connecting a university account. Cloud synchronization between devices is outside the current scope.

Will it connect to my university account and timetable?+

We will investigate optional university sign-in and read-only import of your own timetable, subject to university approval. Authentication and timetable access require separate confirmation; neither is approved or implemented yet. We will not build a feature that collects university passwords.

What about cancelled or rescheduled classes?+

We plan to support changing or cancelling a single occurrence and restoring it later. A public holiday will never automatically remove a class.

Will classmates see my personal plans?+

The timetable format is designed to exclude personal plans, coursework and private notes. Full backups contain private data and will have a separate entry point and file format.

你可能想了解

现在可以下载使用了吗？+

还不可以。当前应用是“今天”占位页和基础工程，本页界面为设计示意。验证过的安装包准备好后，官网会提供下载入口。

需要注册账号或连接云端吗？+

手动安排与文件导入按无需注册、可以离线使用来设计。不连接学校账号，也应能使用这些基本功能。跨设备云同步不在当前范围内。

会接入九大账号和个人课表吗？+

计划在学校批准的前提下，探索可选的学校登录和本人课表只读导入。身份认证与课表数据访问需要分别确认，目前尚未获批或实现。不会开发收集学校密码的功能。

临时停课或调课怎么办？+

计划支持仅修改或取消某一次课程，之后可恢复原安排。学校校历不同于法定节假日，不会因为是假日就自动删掉课程。

分享课表会暴露个人安排吗？+

课表分享格式明确排除个人安排、作业和私密备注。包含私人数据的完整备份，会使用独立的入口和文件格式。
