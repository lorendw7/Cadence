最初のバージョンで目指すこと

📚

授業を整理

学期、時限、第何週かを管理。奇数・偶数週や指定週の授業、教室と担当教員を記録します。

🗓️

自分の予定も一緒に

約束、自習、サークル活動などを授業と同じ週表示に。単発、終日、シンプルな毎週の繰り返しを予定しています。

↪️

休講・振替に対応

その回だけの休講、日時や教室の変更を記録。元の予定へ戻せる仕組みを設計しています。

✅

課題と試験

科目に紐づく課題、締切、完了状態を管理。試験は時間のある予定として表示します。

🕘

今日と今週がわかる

授業と予定をまとめ、時間の重なりを知らせます。課題の締切は、時間を占有する予定と区別します。

📤

クラスメートと時間割を共有

内容を確認して時間割ファイルを渡す方式。個人の予定、課題、私的なメモは時間割共有に含めません。

小さく、ローカルに

アカウント、クラウド同期、外部カレンダー接続は予定していません。端末内の保存と、利用者が選んで行うファイル共有・バックアップを実装します。現在は保存機能も未実装です。

デスクトップを中心に

Windows・Linux・macOS が開発対象です。各 OS で動作確認してから対応版を案内します。Android のプロジェクトは将来用に保持しています。

配布は GitHub Releases を予定しており、ストアへの公開は予定していません。ダウンロードは検証済みパッケージの公開後に案内します。

Cadence

Courses and personal plans, together.

Today's classes, your next appointment and approaching deadlines. A local planner for students and classmates.

Free and open source · Designed without accounts · Windows / Linux / macOS

In development: the app currently shows a Today placeholder. The features below are planned; a feature-complete release is not yet available.

Design and roadmapView source

The first version we are building

📚

Organize your courses

Set up semesters, periods and teaching weeks. Plan odd/even or selected weeks, with rooms and teachers.

🗓️

Make room for your own plans

Appointments, study sessions and clubs alongside courses. One-off, all-day and simple weekly arrangements are planned.

↪️

Handle class changes

Cancel or move one occurrence, change its room and restore the original without rewriting the semester.

✅

Track coursework and exams

Course-linked tasks, deadlines and completion. Exams appear as timed arrangements.

🕘

See today and this week

One schedule for classes and personal plans, with overlap warnings. Deadlines are distinct from reserved time.

📤

Share a timetable with classmates

Preview and exchange a timetable file. Personal plans, coursework and private notes stay out of timetable sharing.

Small and local

No accounts, cloud sync or external calendar connections are planned. We will build local storage, user-directed file sharing and backup. Persistence is not implemented in the current skeleton.

Desktop first

Windows, Linux and macOS are development targets. Each will be described as supported only after native runtime validation. The Android project is retained for future work.

Distribution is planned through GitHub Releases, not app stores. Download links will be added when verified packages are available.

课程与个人安排，放在一起。

第一版要做好的事情

📚

把课程排清楚

设置学期、节次和教学周，支持单双周与指定周上课，记录教室和教师。

🗓️

也安排自己的生活

约会、自习、社团活动与课程放在同一个周视图。计划支持单次、全天和简单的每周重复安排。

↪️

处理临时调停课

仅取消或移动某一次课、修改教室，并可恢复原安排，不必重做整个学期课表。

✅

管理作业和考试

关联课程的作业、截止时间与完成状态；考试作为有明确时间的安排展示。

🕘

看清今天和本周

课程与个人安排统一展示，时间重叠时提示。任务截止时间与占用时段的日程分开处理。

📤

给同学分享课表

预览后导出课表文件。个人安排、作业和私密备注不会进入课表分享文件。

保持简单，数据留在本机

不规划账号、云同步或外部日历接入。后续实现本地保存、由用户主动操作的文件分享和备份。当前应用骨架尚未实现数据持久化。

桌面端优先

开发目标是 Windows、Linux 和 macOS，各端完成实际运行验证后再标注可用。Android 工程保留用于后续开发。

计划通过 GitHub Releases 分发，不上架应用商店。验证过的安装包发布后，官网再提供下载入口。
