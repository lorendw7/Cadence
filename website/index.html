01 / THE EVERYDAY ESSENTIALS

見たいのは、次の一歩。

今と一週間をつなぐ、三つの入口を設計しています。以下は開発予定の機能です。

01

今日に、集中する。

時間順の予定と未完了のタスクを確認できる設計です。集中する時間、打ち合わせ、日常の用事を同じ流れに並べます。

仕事、学習、個人の予定を並べ、日時や場所を編集する計画です。毎週の繰り返しには明確な終了日を設けます。

03

やることを書きとめ、終えたらチェックする機能を計画しています。仕事の準備、学びたいこと、暮らしの小さな用事に。

02 / LOCAL BY CHOICE

予定は手元に。残し方は自由に。

以下は開発中のデスクトップ版の設計です。日程とタスクは自分の端末で扱い、初回に「この端末に保存」か「一時的に使う」を明示的に選びます。保存機能はまだ実装されていません。

データの扱いを詳しく読む↗
  1. 1

    最初に、残し方を選ぶ

    端末内保存と一時利用のどちらも、アカウントなしで使える設計です。保存を選ぶ前に、個人の日程をディスクへ書き込みません。

  2. 2

    ネットにつながず、予定を整える

    基本の日程・タスク機能はオフラインで動く計画です。一時利用の内容は終了で失われ、端末内保存を選んだ内容は次回も開ける設計にします。

  3. 3

    大切な予定は、自分で備える

    JSON の書き出しと、確認してからの復元を計画しています。バックアップには私人の情報が含まれます。端末内保存もバックアップの代わりにはなりません。

03 / A PROJECT IN PROGRESS

今あるものから、一歩ずつ。

開発計画を GitHub で読む↗

  1. 現在 · 学習用アプリ

    タスクの基本操作

    デスクトップの学習用アプリでは、追加・完了・削除・直前の削除の取り消しが動きます。データはメモリー内だけで、終了すると失われます。

  2. 次の段階 · デスクトップ優先

    毎日の予定と、端末内保存

    予定、週間表示、繰り返し、初回の保存方法の選択と復元を、少しずつ実装・検証します。まず Windows・macOS・Linux のローカル利用を育てます。

  3. その先 · 任意の拡張

    Web と同期は、必要になってから

    ブラウザー版と端末間同期は、後の段階で検討する任意の拡張です。基本のローカル利用に、アカウント・学校所属・外部サービスは必要ありません。

現在は学習用アプリの段階です。このページの画面や保存・オフライン設計は、完成した製品の提供を意味しません。

使い始める前に。

?
アカウントや所属は必要ですか？+

基本機能は登録や所属の確認なしで使う設計です。仕事、学習、家事など、用途を問わず自分の端末で使える時間管理ツールを目指しています。

このプレビューに入力した内容は残りますか？+

残りません。表示切替とチェック操作は、架空のデータを使ったデザイン例です。ここでの操作を保存する機能はありません。将来の端末内保存や JSON バックアップは未実装です。

入力したデータは送信されますか？+

このサイトには個人の日程やタスクの入力・アップロード機能はありません。表示には GitHub Pages への通信があり、ホスティング側で基本的なアクセス情報が記録される場合があります。開発中のアプリは、個人データを端末で扱う設計です。

オフラインでも使えますか？+

デスクトップ版では、基本の日程・タスク・選択した端末内保存をオフラインで使える設計です。Web 版や同期は任意の後続機能で、ローカル利用の条件ではありません。これらの製品機能は順次実装・検証する予定です。
