学生・教員・忙しい社会人のために。祝日つき、アカウント不要。

Windows 版をダウンロード GitHub Android — Google Play 準備中
📚

時間割

1限〜6限の時限グリッドと学期の期間設定。授業は祝日を自動でスキップします（休講）。

💰

シフトと給料

バイト先ごとにシフトを記録し、今月の見込み給料を表示。時給の変更にも対応します。

🎌

祝日は自動、更新も自由

日本の祝日は祝日法のルールから計算するので、毎年の更新は不要。他の国・地域の祝日はファイルを読み込むだけ。祝日なしの表示も選べます。

💊

習慣

ワンタップのチェックイン、連続記録（ストリーク）、月間ヒートマップ。

⏱️

集中

授業や課題に紐づくポモドーロ。科目ごとの勉強時間が数字で見えます。

🔔

予定を逃さない

多段リマインダー（前日・30分前・10分前）、了解するまで鳴り続けるモード、朝のダイジェストと夜の予告、ダブルブッキング警告。

📤

LINE で共有

時間割をファイルや画像カードとして、OS の共有シートからそのまま送信。サーバーは一切介在しません。

あなたのデータは、あなたのものです

Cadence にはサーバーもアカウントもなく、ネットワーク権限を要求しません。
すべては端末内の 1 つの SQLite ファイルに保存されます。いつでも JSON / CSV に書き出し、別の端末に読み込めます。永久に無料、広告なし、トラッキングなし。

Cadence

Timetable, meetings, shifts, habits and focus — one offline planner for life in Japan.
For students, teachers and busy professionals. 祝日 included, no account needed.

Free · Open source (MIT) · 100% offline · 日本語 / English / 简体中文
Download for Windows GitHub Android — coming to Google Play
📚

時間割 Timetable

A real period grid (1限–6限) with term dates. Classes skip public holidays automatically.

💰

Shifts & pay

Track part-time shifts per workplace and see your estimated monthly pay — wage changes included.

🎌

Holidays, self-updating

Japanese holidays are computed from the law, so they never need a yearly update. Import a file for any other region — or turn holidays off entirely.

💊

Habits

One-tap daily check-ins, streaks, and a monthly heat-map that keeps you honest.

⏱️

Focus

A Pomodoro that attaches to your classes and to-dos — study hours per subject, made visible.

🔔

Never miss a meeting

Layered reminders (a day before, 30 min, 10 min), an insistent mode that re-rings until acknowledged, morning digest and evening preview, and double-booking warnings.

📤

Share to LINE

Send timetables as files or image cards through the system share sheet — no server involved.

Your data stays yours

Cadence has no server, no account, and requests no network access.
Everything is stored in a single SQLite file on your device. Export all of it to JSON or CSV anytime — and import it back on any device. Free forever, no ads, no tracking.

Cadence

课表・会议・兼职・习惯・专注 — 为在日本生活而做的离线日程本。
面向学生、教师与忙碌的上班族。内置日本节假日，无需注册账号。

免费 · 开源 (MIT) · 完全离线 · 日本語 / English / 简体中文
下载 Windows 版 GitHub Android — 即将上架 Google Play
📚

课表（時間割）

真正的节次网格（1限–6限）与学期起止日期。上课自动跳过节假日（休講）。

💰

兼职与工资

按打工地点记录班次，随时查看本月预计收入，支持时薪调整。

🎌

节假日自动计算，也可自行更新

日本节假日按法律规则计算，无需每年更新；其他国家和地区导入文件即可使用，也可以选择完全不显示节假日。

💊

习惯

一键打卡、连续天数、每月热力图，让坚持看得见。

⏱️

专注

与课程、待办绑定的番茄钟，每个科目的学习时长一目了然。

🔔

不再错过安排

多重提醒（前一天・30分钟前・10分钟前）、确认前反复响铃模式、早间摘要与晚间预告，以及时间冲突警告。

📤

分享到 LINE

通过系统分享面板，把课表以文件或图片卡片发出去——全程不经过任何服务器。

你的数据，始终属于你

Cadence 没有服务器、没有账号，也不申请网络权限。
所有内容都保存在你设备上的一个 SQLite 文件里。随时导出为 JSON 或 CSV，也能在任何设备上导入回来。永久免费，无广告，无追踪。
